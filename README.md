## 格式说明

| 格式 | 说明 |
|---|---|
| `.pdf` | 绝大部分试卷与答案是**扫描件**，正文没有文本层：不能复制文字，也不支持全文搜索。这是原始文件本身的形态。 |
| `.doc` | 旧版 Word 二进制格式，GitHub 不能在线预览，只能下载。 |
| `.docx` | 现代 Word 格式，GitHub 可以在线预览。 |
| `.xlsx` | 英语试题的词汇整理表，按教材版本（新课标 / 人教版 / 北师大版 / 外研版 / 译林版）分别提供。 |
| `.mp3` | 济宁三模的英语听力音频。 |

> `语文/（0227）Z20语文答案.pdf` 是由同名 `.doc` 用 LibreOffice 转换而来的**副本**，只为方便在线查看；原文件 `.doc` 同时保留。
> LibreOffice 的分页可能与 Microsoft Word 存在差异，以 `.doc` 原件为准。
